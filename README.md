# Stock Electrónica

Control de stock de componentes electrónicos. Web + móvil (PWA), con mini-IA offline que reconoce códigos (LM324, DRV8825, Q6015L5…), autocompletado, búsqueda con filtros y base compartida en Supabase.

## Uso local

Abrir `index.html` en el navegador.

## Base compartida

1. Crear proyecto gratis en [Supabase](https://supabase.com).
2. Correr `supabase.sql` en SQL Editor.
3. En la app: botón **Nube** → Conectar → Sincronizar.

## Deploy

Sitio 100% estático: funciona en Netlify, Vercel o GitHub Pages sin build.
